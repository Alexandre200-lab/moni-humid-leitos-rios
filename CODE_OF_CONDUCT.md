# Código de Conduta

## Nosso compromisso

Comprometemo-nos a tornar a participação neste projeto uma experiência livre de
assédio para todas as pessoas, independentemente de idade, identidade, gênero,
orientação sexual, deficiência, etnia, religião ou nível de experiência.

## Conduta esperada

- Use linguagem acolhedora e respeitosa.
- Respeite opiniões e experiências diferentes.
- Aceite críticas construtivas com boa vontade.
- Foque no que é melhor para o projeto e para a comunidade.

## Conduta inaceitável

- Uso de linguagem ou imagens sexualizadas, assédio ou intimidação.
- Comentários ofensivos, ataques pessoais ou políticos.
- Publicação de informações privadas de outras pessoas sem permissão.

## Aplicação

Casos de conduta inaceitável podem ser reportados ao mantenedor do repositório
via issue privada ou pelo e-mail associado à conta `Alexandre200-lab` no GitHub.
Todas as reclamações serão analisadas de forma justa e confidencial, podendo
resultar em advertência ou banimento temporário/permanente.

Este código de conduta é baseado no
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
